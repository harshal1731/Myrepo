[3] DEPLOYMENT STEPS (Azure ACR) - Greystar


1. Show ACR Credentials:
az acr credential show --name faprojectcontainer

2. Login to ACR:
az acr login --name faprojectcontainer

3. Build Local Docker Image:
docker build -t greystar-invoice-api:v2 .

4. Local Debugging 
docker run -d -p 8000:8000 greystar-invoice-api:v2

5. Tag Local Image for Azure:
docker tag greystar-invoice-api:v2 faprojectcontainer.azurecr.io/greystar-invoice-api:v2

6. Push Image to ACR:
docker push faprojectcontainer.azurecr.io/greystar-invoice-api:v2

7. Verify Image in Registry:
az acr repository list --name faprojectcontainer --output table

8. Update Container App to Deploy:
az containerapp update --name acacium-self-bill --resource-group QX-SOFT-UK --image faprojectcontainer.azurecr.io/bill-processor:v18
