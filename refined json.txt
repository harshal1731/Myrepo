2. 
Endpoint Name: /api/upload-expense-report
HTTP Method: POST
Content-Type: multipart/form-data
Input (Multipart Form Parameters):
expense_file (Optional, Binary File. Allowed extensions: .xls, .xlsx)
Output (Response Body - Rough Schema):
If file is provided:
{
  "message": "Uploaded Excel data loaded into RAM successfully.",
  "loaded": {
    "expense_file": {
      "rows_processed": 120,
      "status": True
    }
  }
}

If no file is provided:
{
  "message": "No expense_file supplied. Existing in-memory expense data was unchanged.",
  "loaded": {}
  "status": False 
}
